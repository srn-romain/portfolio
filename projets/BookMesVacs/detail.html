Projet BookMesVacs

Information sur le projet

  • Date du Project: Mai 2023
  • Technologies utilisées: PHP, HTML, CSS, JavaScript & Xampp
Télécharger 11,7 Mo Voir la version web (angular)

Quelques mots sur le projet

L'objectif de ce projet de première année de BTS est de mettre en pratique et renforcer l'ensemble des compétences acquises, notamment la création de sites web dynamiques intégrant la gestion des données. Ce projet a été codé en PHP, avec les données stockées sur PhpMyAdmin via XAMPP.

Le projet fait l'objet d'une modernisation et d'une adaptation avec le framework Angular actuellement disponible en ligne
