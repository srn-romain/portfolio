Quelques mots sur le projet

Avec l'aide de l'IA j'ai réalisé un projet qui mélange deux, de mes centres d'intérêts : le développement web et les séries. L’idée ? Un site de quiz où le but est de deviner la série à partir de quatre personnages affichés à l’écran. Simple, mais addictif !

Le site est développé en HTML, CSS et JavaScript, avec une base de données sur un fichier json.

Les joueurs peuvent choisir leur niveau de difficulté, filtrer le quiz, débloquer des badges en fonction de leurs performances, et même partager leurs résultats sous forme de PDF.

Documentation technique
  • JavaScript : Manipulation dynamique du DOM et gestion d'états avec des patterns
  • Architecture modulaire : Organisation du code en composants réutilisables
  • LocalStorage API : Persistance des données utilisateur et des scores entre les sessions
  • Animations CSS : Transitions et retours visuels
  • Responsive design : Interface adaptative pour une utilisation possible sur tous les appareils
  • Système de génération PDF : Fonctionnalité d'export des résultats pour partage
  • Architecture SPA : Application monopage avec navigation dynamique sans rechargement de page
