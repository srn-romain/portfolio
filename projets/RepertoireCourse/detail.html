Quelques mots sur le projet

Cette application est une plateforme complète de suivi sportif.
Chaque utilisateur dispose d'un compte sécurisé pour gérer son carnet de course. L'interface propose un CRUD enrichi, des statistiques interactives avec graphiques de progression et un système automatique de badges de records. Un volet communautaire permet de partager ses activités, d'interagir via des mentions "J'aime" et de filtrer les résultats par lieu ou distance. L'outil intègre également une wishlist pour planifier ses objectifs, l'exportation de rapports en PDF et la sauvegarde des données au format JSON.

Note : Ce projet personnel est en constante évolution. Il est possible que les captures d'écran ne soient pas à jour.

Documentation technique
  • HTML5 sémantique : Structure optimisée pour l'accessibilité
  • CSS : Utilisation des techniques tels que les variables, les animations ou encore les transitions
  • Stockage d'images en Base64 : Images enregistrées sous forme de chaînes de caractères encodées (format data:image/jpeg;base64)
  • JavaScript : Implémentation de fonctionnalités interactives (calcul de performance, suivi d'entraînement)
  • Optimisation mobile-first : Application optimisée pour une utilisation sur smartphone et tablette
  • Système d'authentification : Protection des fonctionnalités avec système de compte géré via firebase authentification
