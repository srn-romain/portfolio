Quelques mots sur le projet

Mon projet est un répertoire personnel de séries que j'ai regardées. Chaque série est enregistrée dans Firebase avec une image, son titre et la date à laquelle je l'ai visionnée.

J'ai ajouté plusieurs fonctionnalités pratiques : je peux ajouter de nouvelles séries facilement en déposant une image par glisser-déposer, modifier les informations d'une série existante ou la supprimer si besoin. Pour protéger ces actions, j'ai mis en place un mot de passe.

Les séries sont présentées par cartes avec leur visuel, classées par date de visionnage. Un système de filtrage par année permet de retrouver rapidement les séries vues à une période précise.

Ce projet me permet de garder une trace visuelle et organisée de toutes les séries que j’ai vues au fil du temps.

Documentation technique
  • Firebase Realtime Database : Stockage et synchronisation des données en temps réel
  • Firebase Storage : Gestion efficace du téléchargement et stockage des images
  • Drag & Drop API : Implémentation d'une interface intuitive de glisser-déposer pour les images
  • Architecture SPA : Application monopage avec routage client-side sans rechargement
  • Système d'authentification : Protection des fonctionnalités administratives avec authentification
