À propos du projet

Ce projet développer en WebGL, GLSL & JavaScript permet de visualiser une scène contenant des lettres 3D. L'objectif est de comprendre et manipuler :

  • La création et l'affichage d'un objet 3D.
  • L'utilisation des matrices de transformation pour la projection et la caméra.
  • La gestion du champ de vision pour un rendu en perspective.
  • Le déplacement de la caméra pour explorer la scène sous différents angles.
  • Le rendu de plusieurs objets avec des couleurs distinctes via les shaders.
Documentation technique
  • Programmation WebGL : Manipulation directe du contexte de rendu graphique bas niveau
  • Shaders GLSL : Écriture de vertex et fragment shaders pour le rendu personnalisé
  • Mathématiques 3D : Application des matrices de transformation et calculs vectoriels
  • Architecture graphique : Pipeline de rendu et gestion efficace des ressources GPU
  • JavaScript avancé : Communication entre le CPU et le GPU via l'API WebGL
